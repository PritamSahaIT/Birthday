# 🎂 Happy Birthday Pratyusha! ✨

A magical, interactive birthday surprise website crafted specially for **Pratyusha**.

---

## 🌟 Highlights & Features

1. **🎁 The Grand Entrance**:
   - 3D pulsing gift box unwrapping experience with ribbon animations and celebratory confetti explosion.
2. **🎵 Built-in Crystal Music Box Audio**:
   - Native Web Audio API synthesizer that plays a gentle, sweet "Happy Birthday" melody without needing any external MP3 files!
   - Vinyl record toggle button to start/stop the melody at any time.
3. **🎂 Interactive Birthday Cake & Wish Ceremony**:
   - Multi-tier animated birthday cake with flickering candles.
   - Blow out individual candles or tap "💨 Blow Out All Candles" to trigger realistic smoke, fireworks, and a magical wish-granted celebration!
4. **💌 The Wax-Sealed Secret Letter**:
   - 3D envelope with a personalized "**P**" wax seal.
   - Unfolds into a parchment letter with heartfelt words for Pratyusha.
   - Built-in "✏️ Edit Letter Note" editor to quickly personalize the text.
5. **📸 Memory Polaroid Scrapbook**:
   - Aesthetic tilted polaroids with masking tape and pins.
   - Includes instant "📸 Add / Change Photos" button that lets you pick pictures from your computer and saves them right in the browser!
   - Click any polaroid to zoom into full resolution.
6. **🎈 Balloon Pop Compliment Garden**:
   - 5 interactive balloons that bounce gently.
   - Tap any balloon to pop it with realistic sound effects and unlock reasons why Pratyusha is treasured!
7. **🏮 Sky Lantern Wishing Ceremony**:
   - Type a personal birthday wish and hit "Release Lantern" to launch a glowing sky lantern that drifts upwards into the starry night sky.

---

## 🚀 How to Open and View

1. **Directly in your browser**:
   - Simply double-click **`index.html`** in this folder to open it in Google Chrome, Microsoft Edge, or any modern web browser.
2. **Or run a local server (PowerShell)**:
   ```powershell
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080` in your browser.
